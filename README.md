# Проект "Парсер вакансий с HeadHunter"

Проект представляет собой приложение для поиска и фильтрации вакансий с сайта HeadHunter.ru.

## Описание:

Приложение позволяет:
- Искать вакансии по ключевому слову на HeadHunter
- Фильтровать найденные вакансии по:
  - Ключевым словам в описании
  - Диапазону зарплат
- Сортировать вакансии по зарплате
- Сохранять результаты в JSON файл
- Получать топ N вакансий

## Технологии

- Python 3.13
- Poetry для управления зависимостями
- Requests для работы с API
- Pytest для тестирования
- Mypy для статической типизации
- Black для форматирования кода
- Flake8 для проверки стиля кода

## Использование:

1. Для запуска программы используйте функцию модуля `main.py`.

2. Следуйте инструкциям в консоли:
- Введите ключевое слово для поиска вакансий
- Введите ключевые слова для фильтрации результатов
- Укажите количество вакансий для вывода
- Введите диапазон зарплат (например: 100000-150000)


## Структура проекта

- src/
  - classes.py - классы для работы с API HeadHunter
  - json_saver.py - класс для работы с JSON файлами
  - utils.py - спомогательные функции
  - vacancy.py - класс для работы с вакансиями
- tests/ - модульные тесты
- main.py - основной скрипт приложения
- pyproject.toml - конфигурация Poetry и инструментов


## Тестирование

Для тестирования проекта используется библиотека 'pytest'. Чтобы запустить тесты, выполните команду:
'pytest'

Для получения отчета о покрытии тестами выполните команду: 
pytest --cov=src --cov-report=html
